# Automatic Brightness Adjuster for Windows

A windows utility that automatically adjusts a monitor's brightness based on light measured from the webcam.

## Installation

1. Install Python
2. Create and activate a virtual enviroment
3. Install dependencies:
   pip install -r requirements.txt
4. Run the application
   python main.py

## Configuration

Brightness behaviour can be changed in `settings.ini`

## Known issues

Slight monitor flickering while the program is running and after it has stopped.
